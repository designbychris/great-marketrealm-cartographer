VI.6D.15A — The Keeper's Roadworks

Adds a paintable Road terrain material to the existing version-1 scene cells. Roads save through the existing scene endpoint, are erasable with Erase, and display in both Classic and Pixel illustrated views. No scene migration, new endpoint, or changes to building footprints. This is a functional groundwork pass; connected cobblestone shapes and additional surfaces follow in 15B/15C.

Smoke test: select Road, drag across empty cells, save, reload, switch illustration styles and rotate all four directions; erase some road cells and save again. Verify existing saved scenes still load.
