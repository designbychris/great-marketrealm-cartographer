# VI.6D.8 — Pippin Opens the Keeper’s Building Palette

Adds a visual, Pattern Book-driven selector to the construction grid. Painted Cottage and Village House use approved 0° thumbnails. Planned Bakery, Blacksmith and Market Stall appear disabled. Choosing a painted pattern applies the appearance to a selected cottage, or prepares placement of a new cottage-footprint structure. No new prefab geometry, persistence fields, illustration camera, or depth rules.

Manual check: select Village House with no object selected, place it on an empty 2×2 grid, save/reload, view at all four angles. Select an existing cottage and choose the other painted pattern; save/reload. Verify planned cards are disabled.
