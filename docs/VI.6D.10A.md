# VI.6D.10A — The Storybook Foliage Standard

A presentation-only foliage registry establishes five initial MarketRealm varieties and future expansion collection identifiers. No unapproved illustrated sprites are shipped in this phase; all five entries intentionally have `views: null` and the existing tree artwork continues to render unchanged. The renderer will only use fully registered four-view sprites with validated local paths and positive dimensions. Variety choice is deterministic per world cell, independent of camera direction. Existing tile materials, edit controls, save format, tree occlusion, and Classic illustration are unchanged.

## Next visual work

VI.6D.10B paints and integrates five four-view trees. Follow-on terrain work will retain the logical tile grid while optionally hiding tile outlines in illustrated mode, and water will gain sparse deterministic ripples with reduced-motion-safe occasional animation. Those effects are deliberately excluded from this structural push.
