# VI.6B.8 — Pippin Takes the World in His Hands

- Drag horizontally across the illustrated landscape with a mouse or pointer; on touchscreens, horizontal swipes turn the scene while vertical page scrolling remains available.
- Release after a 36px drag to snap to one of four authoritative isometric directions; longer gestures may turn multiple quarter-steps.
- Left/right buttons continue to work. A short crossfade provides an animated view transition, disabled when the visitor requests reduced motion.
- Camera changes do not change the saved scene, construction object positions, or building rotations.
- The effect is a transition between four projections, **not** continuous 3D orbiting.
- Test all four directions, pointer cancel, vertical scrolling on mobile, button rotation and reduced-motion settings.
