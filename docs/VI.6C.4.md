# VI.6C.4 — Pippin Learns Which Wall Is Which

World-space facade anchors replace screen-space offsets for doors and windows. The visible wall is selected from the four supported camera orientations. Chimneys are anchored to a roof-slope elevation, then drawn as vertical world-space geometry. Architectural ink uses the same facade. No changes to scene persistence, prefabs, catalogue styles, camera state or painter ordering.

Check each direction at 150% zoom, particularly openings, chimneys and overlaps near foliage. The four-direction facade selection is a presentation technique, not a full 3D geometry engine.
