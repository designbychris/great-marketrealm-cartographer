# VI.6D.3 — Pippin Paints the MarketRealm Cottage

First original four-view illustrated cottage asset pass. Four transparent 192 × 178 PNGs replace the initial geometric placeholders in the existing reusable building catalogue. Each is a cohesive miniature with tiled terracotta roof, masonry chimney, timber-framed plaster walls, windows, door, stone foundation and planting. The image is view-only: the 2 × 2 footprint, scene state, object identity, rotation and existing occlusion ordering remain authoritative.

The four directions share the same canvas, baseline and silhouette to avoid stretched triangular projections. The `pixel` mode continues to select the illustration; `classic` continues to use the existing procedural architecture. The building art is deliberately a first authored sprite pass, not yet a hand-painted production illustration equivalent to the user's reference. No new persistence or gameplay changes.

Browser QA: at 100% zoom inspect the cottage at 0°, 90°, 180° and 270°, toggle Classic and Pixel-inspired art, test rotate and drag, check foliage/roof overlap and depth guides, then test 150% zoom and reset.
